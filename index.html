Building now

Busscript Oct 2026

A CAN bus analyzer in the style of Vector CANalyzer, with a built-in MCP server so an AI assistant can read a bus too. Python core, React interface, its own small scripting language, and import for MF4, ASC, BLF, candump, TRC and CSV recordings. Ships as a single Windows .exe with a native window. Not yet tested on real CAN hardware.

Snack Cabinet Lock Sep 2026

A cabinet that opens when I tap my phone on it. A custom Android app on my Galaxy S22 answers a Raspberry Pi's RC522 reader with a rotating six-digit code. The common library for that reader only handles part of the protocol, so the Pi-side code speaks the rest directly. Phone-to-reader unlock works end to end; the cabinet itself is still being wired.

VoltForge

A 3D design and simulation tool for electric bikes. You assemble a bike on screen and it checks that the parts fit together and estimates how fast a given rider would go.
